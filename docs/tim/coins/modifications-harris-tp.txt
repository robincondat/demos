1. OBJECTIF ET CHAÎNE À OBTENIR
-----------------------------

Image en niveaux de gris uint8
  -> Sobel 3 x 3 normalisés, sortie float32
  -> produits Ix², IxIy, Iy²
  -> sommes uniformes sur un bloc blocksize x blocksize
  -> score R = det(M) - k * trace(M)²
  -> seuillage relatif alpha * max(R)
  -> maxima locaux 3 x 3, sans la bordure extérieure
  -> tri décroissant des scores
  -> sélection gloutonne selon une distance euclidienne
  -> éventuel affinage subpixel.

3. VERSION DE RÉFÉRENCE POUR LE CALCUL MANUEL
-------------------------------------------

Ce code conserve le détail des opérations pour accompagner les exercices.
Il vise la même chaîne que le chemin CPU OpenCV. Les différences d'arrondi
ou d'optimisation peuvent empêcher une égalité bit à bit des scores.

    import cv2
    import numpy as np

    def NMS_opencv(R, mask, min_distance, max_corners=0):
        yc, xc = np.nonzero(mask)
        scores = R[yc, xc]

        # Score décroissant, puis y décroissant, puis x décroissant.
        order = np.lexsort((-xc, -yc, -scores))
        selected = []
        distance2 = min_distance ** 2

        for index in order:
            x, y = int(xc[index]), int(yc[index])
            if any(
                (x - x0)**2 + (y - y0)**2 < distance2
                for x0, y0 in selected
            ):
                continue

            selected.append((x, y))
            if max_corners > 0 and len(selected) >= max_corners:
                break

        return np.asarray(selected, dtype=np.float32).reshape(-1, 2)


    def Harris_corner_detection(
        img, blocksize=5, k=0.04, alpha=0.01,
        min_distance=7, max_corners=0
    ):
        if img is None or img.ndim != 2 or img.dtype != np.uint8:
            raise ValueError("L'image doit être en niveaux de gris uint8.")

        scale = 1.0 / (4 * blocksize * 255)
        Ix = cv2.Sobel(
            img, cv2.CV_32F, 1, 0, ksize=3,
            scale=scale, borderType=cv2.BORDER_DEFAULT
        )
        Iy = cv2.Sobel(
            img, cv2.CV_32F, 0, 1, ksize=3,
            scale=scale, borderType=cv2.BORDER_DEFAULT
        )

        def aggregate(product):
            return cv2.boxFilter(
                product, -1, (blocksize, blocksize),
                normalize=False, borderType=cv2.BORDER_DEFAULT
            )

        Sxx = aggregate(Ix * Ix)
        Sxy = aggregate(Ix * Iy)
        Syy = aggregate(Iy * Iy)
        R = ((Sxx * Syy - Sxy**2) - k * (Sxx + Syy)**2).astype(np.float32)

        _, R_seuil = cv2.threshold(
            R, float(alpha * R.max()), 0, cv2.THRESH_TOZERO
        )
        corner_candidates = R_seuil != 0
        local_max = cv2.dilate(R_seuil, None)
        corner_maxima = corner_candidates & (R_seuil == local_max)
        corner_maxima[[0, -1], :] = False
        corner_maxima[:, [0, -1]] = False

        corners = NMS_opencv(R, corner_maxima, min_distance, max_corners)
        return R, corner_candidates, corner_maxima, corners

Les autres sorties servent aux visualisations des étapes intermédiaires.
La NMS présentée privilégie la lisibilité ; OpenCV accélère les recherches
de voisins en organisant les points dans une grille spatiale.
